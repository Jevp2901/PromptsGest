# PromptsGest

Plataforma para centralizar, catalogar y generar prompts optimizados, aplicando principios de **Prompt Engineering** para maximizar el rendimiento de modelos de lenguaje (LLMs).

---

## 📌 Descripción del Proyecto

**PromptsGest** es un aplicativo web diseñado para gestionar el ciclo de vida completo de los *prompts*. Facilita la creación, organización y optimización de instrucciones para Inteligencia Artificial mediante metodologías avanzadas de ingeniería de prompts, reduciendo la alucinación y garantizando respuestas precisas y consistentes.

---

## 🚀 Características Principales

* **Centralización y Catalogación:** Almacenamiento organizado de prompts clasificados por categorías, uso y tipo de modelo.
* **Generador Inteligente:** Interfaz asistida para estructurar instrucciones especificando rol, contexto, restricciones y formato de salida.
* **Optimización con Prompt Engineering:** Integración de patrones como *Few-Shot*, *Chain-of-Thought* y directrices de formato para elevar el rendimiento de los LLMs.
* **Historial y Versionado:** Control de cambios para iterar y perfeccionar la efectividad de cada prompt.
